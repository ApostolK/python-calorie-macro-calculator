# Calorie & Macronutrient Calculator (Python CLI)

Interactive Python command-line application that calculates Basal Metabolic Rate (BMR) via the Mifflin-St Jeor equation, adjusts for daily activity level (TDEE), and breaks down recommended daily protein, fat, and carbohydrate targets based on the user's goal (lose, maintain, or gain weight).

### Run
```bash
python calorie_macro_calculator.py
```

# Kalória- és Makrotápanyag-kalkulátor (Python CLI)

Interaktív parancssori Python alkalmazás, amely a Mifflin-St Jeor képlet alapján kiszámítja az alapanyagcserét (BMR), figyelembe veszi a napi aktivitási szintet (TDEE), majd a megadott célhoz (fogyás, súlytartás, tömegnövelés) igazítva megadja a javasolt fehérje-, zsír- és szénhidrátbevitelt.

### Futtatás
```bash
python calorie_macro_calculator.py
```
